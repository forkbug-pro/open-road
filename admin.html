A removed password stops working right away, even for someone who is already in the game, the next time they open the admin panel. Passwords are stored hashed, so they cannot be shown again after you add them: write them down.

CHANGE THE MASTER PASSWORD

The master password is a secret on the Cloudflare Worker, so it is changed there: in the Cloudflare dashboard open the Worker, Settings, Variables and Secrets, and edit ADMIN_MASTER. Or from a terminal run npx wrangler secret put ADMIN_MASTER. After that the old master password stops working immediately.
